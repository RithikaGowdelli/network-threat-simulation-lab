# Lessons Learned

This section is what separates a portfolio that looks like a checklist from one that shows real judgment. Write it after all four scenarios are complete, in your own words. Suggested prompts — answer these honestly, including the parts that went wrong:

- What was harder than expected, and why?
- Where did your first detection query fail or produce false positives, and what did you change?
- What's a real gap in visibility you found in this lab setup (e.g. Metasploitable2's limited default logging) that you'd need to solve for in a production environment?
- If you had one more week on this lab, what would you add or fix?
- What did this project teach you about the difference between "an attack happened" and "an attack was detected"?
